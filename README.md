## Структура и постоянные ссылки

Иконки: `assets/icons/<app-id>/v1.png`. Идентификаторы приложений — короткие, латиницей, в нижнем регистре: `intraservice`, `bitrix`, `meetings`.

Новая картинка получает новый файл: `v2.png`, `v3.png`. Опубликованные версии не заменяются и не удаляются, чтобы выданные ссылки сохраняли прежнее изображение.

Используем квадратные PNG. Исходный принятый файл сохраняется без изменений. Для добавленной версии указываем фактические размеры в `assets/catalog.json`.

Страницы приложения по мере подготовки размещаются отдельно:

```text
apps/<app-id>/index.html
apps/<app-id>/privacy.html
apps/<app-id>/terms.html
assets/icons/<app-id>/v1.png
```

Политики и условия публикуются после согласования для конкретного приложения. Пока таких страниц в этом репозитории нет; фиктивные документы или общая политика для всех приложений не создаются.

## Подключение иконок к MCP-плагинам

Публичная PNG-ссылка подходит для загрузки изображения и для клиентов, поддерживающих URL иконки. Размещение файла само по себе не меняет оформление подключённого плагина.

В пакете плагина OpenAI изображение включается в его assets, а относительные пути задаются в `plugin.json` через `extensions.com.openai.interface.logo` и `extensions.com.openai.interface.composerIcon`. Это настройки оформления плагина, а не MCP tool и не OAuth-параметры.

Для OMA Bitrix потребуется отдельно согласованная иконка Bitrix. Картинка IntraService не назначается ему автоматически. Новый MCP-сервер ради иконки не требуется. Изменения существующего приложения и его публикация выполняются отдельной задачей.

Официальная документация: https://developers.openai.com/plugins/build/plugins

## Публикация

GitHub Pages публикует ветку `main`, каталог `/`. Файл `.nojekyll` включает обычную раздачу статических файлов. Дополнительные сборщики, зависимости и GitHub Actions workflows не нужны.

Публикуем только открытые материалы. Приватный код, учётные данные и пользовательские данные здесь не хранятся.

Существующий `dmkolt-lab/oma-meetings-public` сохраняет прежнее имя и адреса, уже указанные для Google. Этот репозиторий его не заменяет автоматически.
